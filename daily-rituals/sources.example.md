# Configuration

Copy this file to `sources.md` and fill in your values before using the
daily-ritual skills. `sources.md` is gitignored and must never be committed.

The first `/morning` or `/eod` run **creates a new empty wiki** at `Wiki root`
if that folder does not exist. Do not point this at an existing personal wiki.

| Setting | Your value |
|---------|------------|
| Wiki root | `~/daily-wiki` |
| Google Workspace MCP | `YOUR_GOOGLE_MCP` |
| Google email | `YOUR_EMAIL@company.com` |
| Slack MCP | `YOUR_SLACK_MCP` |
| Slack username (for `from:` search) | `YOUR_SLACK_USERNAME` |
| Atlassian MCP | `YOUR_ATLASSIAN_MCP` |
| Atlassian cloudId | `YOUR_ATLASSIAN_CLOUD_ID` |
| Jira site | `YOUR_COMPANY.atlassian.net` |
| Jira project key | `YOUR_JIRA_PROJECT` |
| Dataverse MCP | `YOUR_DATAVERSE_MCP` |
| Smartsheet MCP | `YOUR_SMARTSHEET_MCP` |
